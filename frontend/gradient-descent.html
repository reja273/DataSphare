Gradient Descent

Learn how a model follows the slope of its loss to improve its predictions—one small parameter update at a time.

The core idea

Imagine standing on a loss landscape. The gradient points uphill, so gradient descent repeatedly steps in the opposite direction. The learning rate, α, sets the step size: too small is slow; too large can overshoot the minimum.

θt+1 = θt − α ∇J(θt)

For linear regression, our parameters are slope m and intercept b, with prediction ŷᵢ = mxᵢ + b. We minimize the mean squared error cost:

J(m,b) = 12n Σi=1n (mxi + b − yi)²

Derive the updates

Apply the chain rule to each squared residual. The derivative of (mxᵢ+b−yᵢ)² is twice the residual multiplied by the derivative of its inside. The ½ in the cost cancels the 2.

Slope gradient

∂J/∂m = (1/2n) Σ 2(mxᵢ+b−yᵢ)xᵢ

∂J/∂m = (1/n) Σ (mxᵢ+b−yᵢ)xᵢ

Intercept gradient

∂J/∂b = (1/2n) Σ 2(mxᵢ+b−yᵢ)

∂J/∂b = (1/n) Σ (mxᵢ+b−yᵢ)

Then update both parameters simultaneously using their current gradients:

m ← m − α (∂J/∂m)    b ← b − α (∂J/∂b)

What to notice

  • The gradients depend on the current prediction errors, so they change as the line moves.
  • Each step reduces loss when the learning rate is suitable.
  • Gradient descent also trains logistic regression and neural networks; their loss functions and gradients differ.
